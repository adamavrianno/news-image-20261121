A TypeScript program that delivers a 1024×1024 typographic news poster summing up Saturday 21 November 2026 world news — six stories, from the missiles in Poland to the first trilateral summit — as entry.png. The poster is rendered by render_poster.py (Python + Pillow, DejaVu Sans) and committed as poster.png.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
